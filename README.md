# Ejercicios Secuenciales — Lógica de Programación

Soluciones en **C#** de los 20 ejercicios de estructura secuencial
del programa ADSO (SENA). Cada ejercicio vive en su propia carpeta.

* **Aprendiz:** Breiner Ramirez
* **Ficha:** 3603305
* **Competencia:** Algoritmos

## Cómo ejecutar
Cada carpeta contiene un archivo Program.cs listo para copiar
en un compilador en línea o en Visual Studio.
